# Qwen PPO Tuning

PPO fine-tuning for Qwen 1.5B using torchtune.

## Overview

This project implements Proximal Policy Optimization (PPO) fine-tuning for the Qwen language model using the torchtune library.

## Installation

```bash
uv sync
```

## Usage

See the `notebooks/` directory for examples and the `configs/` directory for training configurations.
